# 指南与技能维护规范

本文件约束本仓库全部 AGENTS.md、技能及其支持文件的维护。修改这些文件前先读取本文件。

## 内容归属

- 根 AGENTS.md 维护项目公共约束、架构边界及技能入口；包内 AGENTS.md 只补充包的职责和专属契约。
- 根 README.md 面向仓库开发者；包内 README.md 面向安装和使用插件的人，随包复制后仍须独立可读。
- `.agents/skills/{name}/SKILL.md` 维护一类任务的操作流程。仅在任务匹配时加载，已读取的内容无需重复读取。
- 每条规则保留一个权威来源，其他位置按需引用；不复制其他项目的命令、检查器或未提供的工具入口。

## 技能维护

- 每个技能使用独立目录，目录名与 frontmatter 的 name 一致，采用小写字母、数字及连字符。
- SKILL.md 的 frontmatter 使用非空的 name、description；描述说明实际能力及触发条件。
- 技能保持简洁、自包含；仅为真实重复需求新增 scripts、references 或 assets，不创建空目录和占位资料。
- 约束写清触发条件和适用范围，不把只读审查变成构建、修改、提交或前台操作的授权。
- 引用使用相对 Markdown 链接，并说明何时读取。避免重复指南、循环加载及机器绝对路径。
- `.agents` 位于 Unity 资源范围外，不创建 .meta 或程序集。

## 验证

- 检查 frontmatter、目录与名称的一致性、链接目标和未替换占位内容；有可用的技能校验器时一并运行。
- 核对规则与本仓库现有结构、命令和工具一致；格式检查不能代替行为或能力验证。
- 仅修改文档不要求 Unity 编译；同时修改包、程序集或 C# 时，按根指南和验证技能选择对应检查。
- 完成后按 [git 技能](skills/git/SKILL.md) 检查提交范围和验证记录。
